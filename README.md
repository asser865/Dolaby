# Dolaby

Dolaby is an Egyptian brand and e-commerce platform that gathers all Egyptian local brands in one place. It is built with PHP and MySQL, offering a complete shopping experience including product browsing, cart management, user accounts, and a brand owner dashboard for analysis and promotions.
